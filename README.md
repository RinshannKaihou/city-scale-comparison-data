# city-scale-comparison-data

Data for [city-scale-comparison](https://github.com/RinshannKaihou/city-scale-comparison) v2, served by GitHub Pages at
`https://rinshannkaihou.github.io/city-scale-comparison-data/` (CORS `*`). Everything here is generated by the app repo's
`pipeline/` (`uv run python -I -m citydef.export`) — do not edit by hand.

The v1 data (79 stitched road-network JSON files) is preserved at tag `data-v1`.

## Layout

```
cities.json              index: every entry's names, anchor, definition-A stats, metrics, radial profiles (~170 KB)
<entry-id>/
  record.json            the entry's index record
  manifest.json          raster bounds + road file list
  boundary.json          definition A polygon(s)
  builtup.png            building coverage (GHS-BUILT-S 2020, 100 m) inside A, as alpha
  figure_ground.png      building footprints, 1.5 × 1.5 km around the anchor, 2 m/px
  roads_major.bin        motorway…tertiary
  roads_minor/<i>_<j>.bin residential streets in 8 km chunks
```

All coordinates are metres in the entry's own Lambert azimuthal equal-area frame, origin = the entry's anchor (its main city's
traditional centre). Road files: `uint32 header length | JSON header | per section: float32 [x, y]… | uint32 path starts`,
little-endian, 4-byte aligned.

## Sources

- Urban centres, population, built-up surface and volume: GHSL, European Commission JRC (GHS-UCDB R2024A; GHS-POP, GHS-BUILT-S,
  GHS-BUILT-V R2023A).
- Roads and building footprints: Overture Maps Foundation, release `2026-10-21.0`, which includes data © OpenStreetMap
  contributors, available under the ODbL.
